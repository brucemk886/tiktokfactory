# 小说效果核心模块

## 已完成

- 新增管理员入口 `/novel-effects`。
- 官方 TikTok API 与 GeeLark 第三方数据完全分开切换，不混算。
- 按“小说 → 文案/开头版本 → 音频 → 发布视频 → 账号”聚合真实映射数据。
- 汇总小说数、文案版本、音频、测试视频、测试账号、播放、观看、完播、3 秒留存与评论。
- 每个文案版本支持展开对应的视频和账号明细。
- 官方数据仅在发布记录能映射到本地音频时纳入小说效果，无法映射的数据在状态栏明确显示。

## 使用约束

- 官方数据映射优先使用 TikTok 视频 ID；缺少视频 ID 时，使用账号与发布时间（30 分钟窗口）兜底。
- 不生成模拟指标；接口未返回的观看、完播或留存显示为 `—`。
- GeeLark 原有小说自运营和 TikTok 官方 API 自运营页面未改动。

# 测试题中视频模板

日期：2026-09-02
分支：`feature/mid-video`

## 完成内容

- 中视频模板工作台新增 `/quiz`，侧栏名称为“测试题”。
- 页面支持中英文示例题库、6–9 道三选一题目、正确答案、代码插图、标题、开头钩子、结尾互动、每题停留时长和随机种子编辑。
- 新增独立 Remotion 工程 `quiz-video-generator`。成片为 720×1280、30 FPS 的试卷式下滚动画，红笔逐题圈出答案，结尾显示分数互动。
- 本地 `/api/quiz/start` 与 `/api/quiz/progress/:id` 已接入；Cloudflare 同名接口会入 `quiz` 队列，本地工人通过 `quiz-render-job.js` 执行。
- 现有管理员账号通过本地版本 27 迁移和云端动态补全获得该模块；运营账号默认不开放。
- 若内置背景音乐不存在，渲染器自动关闭音乐并继续出片，不会因缺音频失败。
- 云端任务结果保留测试题成片文件名、语言、题数、时长和种子；线上页明确提示成片保存于本地工人输出目录。

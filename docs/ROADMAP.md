# Roadmap

## Current

- Shared project documentation
- Persistent Project Hub state
- Multi-project Agent registration
- Bounded concurrent read-only Agent runs
- Automatic run handoffs

## Next

- Promote approved Agent findings into implementation tasks
- Add scheduled Agent test runs
- Add project health checks and test-command presets
- Add searchable decision and handoff history

## Later

- Migrate orchestration state from JSON to SQLite when concurrent write volume requires it
- Expose Project Hub through a local MCP server
- Add project-level release gates and deployment history

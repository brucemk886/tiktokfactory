# 图文样式、Grokbot 文案与内容效果

## 入口
- `/psychology-publish-designs`：20 套首图/正文真实预览与随机样式测试说明。
- `/psychology-copy-library`：爆款文案列表，每篇原文下通过“改写详情”管理多个图文改写版本。
- `/psychology-publish` → 图文设置：默认选择文案库爆款原文，也可选改写版本或同行爆款，默认每条随机抽取，也可显式选择本批固定/沿用原帖。
- `/psychology-ops-report?tab=content`：相同文案跨账号、同来源不同改写、按样式对比；点击查看账号与作品明细。

## 样式分配规则
默认从全部20套中为每条图文独立随机抽取，同一账号可使用不同样式；随机允许重复，不保证小批次均分。任务创建时将样式固定在任务载荷和效果快照中，同一篇首图与内页使用同一套，重试、重新提交同一批次不会重抽。
账号/分组固定分配已停用，页面移除绑定表单和账号主样式表。旧页面提交 group 模式也按 random 创建新批次；未传 styleMode 的新图文请求默认 random。旧任务继续使用已保存的样式，旧批次重复提交仍返回原任务。显式 fixed/legacy 仍可使用。
样式池作用于纯文字卡片，不额外生成AI图片，选用样式池会将图文页面统一成文字卡片。

## Grokbot 批量改写
1. 文案库的“爆款文案”列表只显示提取完成的内容，可按视频/图文筛选并导出当前页，每页20篇。后续新导入的同行爆款会进入独立后台通道；历史爆款不自动补提取。已有图文缓存或导入时附带的完整原文会直接复用。
2. 将导出的文字交给 Grokbot，要求按下方 JSON 返回。保持 sourceKey 不变，每篇变体使用新的 externalId。建议改变表达角度、具体情境和解释，不只替换同义词；不要虚构研究、统计或诊断。
3. 在对应爆款文案的“改写详情”中新增版本或导入 JSON，来源自动关联；跨来源导入和历史版本可从文案库右上角“批量导入”按钮进入。人工审核首图、每页正文、发布标题和文案；每批1–100篇，每篇1–6页，第一项就是首图。导入即启用，但不会自行发布。
4. 自动发布选择“文案库 · 改写版本”，图文、视频都支持。图文直接使用已保存分页，不再识图或调用AI改写；视频仍调用所选模板编排内容、画面与配音。默认避免相同账号重复使用同一变体；可显式允许复用。

```json
[{"externalId":"attachment-001-v1","sourceKey":"attachment-001","title":"When closeness feels overwhelming","caption":"A reflection on asking for space and staying connected.","pages":["When closeness feels overwhelming","You can need space and still care about someone.","Try saying: I need a quiet evening. Can we talk tomorrow?"]}]
```

同编号同内容重复导入会跳过；同编号不同内容拒绝覆盖，需使用新版本编号。文案可停用，已创建任务继续使用原快照。
目前提供手动新增版本、JSON 导入及原文导出，不使用或消耗 Grokbot 凭证/额度，也未创建新的机器人API。

## 统计口径
同文案指标题、发布文案、逐页叠字一致的版本，和来源分组分开。绑定以本地任务ID + 授权账号 + 官方作品ID精确匹配，不用相同标题或批次猜测。来源和样式在创建时固定，最终文案在生成完成转入绘图时保存。
报表沿用现有日期/分组权限；内容按批次创建时间筛选，当前累计数据来自每账号最近100条归档作品。读取上限5000任务、10000发布记录，超出会提示缩短周期。默认只用满24小时、已有播放数据的作品计算均播、高播率；缺失指标显示 —，不当作0。不同账号、发布时间和题材会影响表现，不能据此认定样式导致流量变化。
历史任务从原生成任务保留的 plan 恢复文案身份；未记录的样式标为未知，缺失文案单独列出。没有官方返回的收藏、完播或观看时长不补造。

## 情感心理学样式更新
现有20套均面向情绪共鸣、关系困惑、内心独白和沟通建议。保留经典黑白、奶油杂志、深夜独白、私信信笺、关系对话、留白引语、极简短句；其余13套已换成情感关系系列。新任务随机池只包含当前20套；历史记录与已创建任务继续使用原样式编号和布局。

## 原文直接用于生产
自动发布的图文和视频均默认“文案库 · 爆款原文”，只抽取已完成的原文，可筛选原素材是图文、视频或全部。图文按原图页序，视频转图文优先采用口播（无口播才用画面文字），以最多6页文字卡片输出；长段落按1500字符切分，超过6页时要求保存精简改写版本。视频以原文正文为模板输入，超过5000字符拒绝创建，不静默截断。原文和改写版本都保留创建时的完整快照。来源标签、依恋风格标签暂不增加；题目揭晓评论仍只用于模板题库。

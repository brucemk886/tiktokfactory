# 图文样式、Grokbot 文案与内容效果

## 入口
- `/psychology-publish-designs`：20 套首图/正文真实预览、分组样式池、单账号覆盖、文案库。
- `/psychology-publish` → 图文设置：选同行爆款或已审核文案库，选跟随绑定/本批固定/沿用原帖。
- `/psychology-ops-report?tab=content`：相同文案跨账号、同来源不同改写、按样式对比；点击查看账号与作品明细。

## 绑定规则
单账号指定 > 分组样式池 > 全部20套。池内按账号ID确定性分配，修改池后仅影响新批次。任务创建时固定样式，不随配置变化或重试变化。绑定属于当前管理员；不会替其他管理员改发布设置。
新页面默认跟随绑定；旧API未传 styleMode 保持 legacy。样式池作用于纯文字卡片，不额外生成AI图片，选用样式池会将图文页面统一成文字卡片。

## Grokbot 批量改写
1. 样式与文案页点击“导出已提取原文”，每次50篇，再次点击下一页。尚未缓存的同行帖子需先完成一次原文提取；此按钮不会隐式调用TikHub/AI。
2. 将导出的文字交给 Grokbot，要求按下方 JSON 返回。保持 sourceKey 不变，每篇变体使用新的 externalId。建议改变表达角度、具体情境和解释，不只替换同义词；不要虚构研究、统计或诊断。
3. 人工审核首图、每页正文、发布标题和文案后，导入 JSON。每批1–100篇，每篇1–6页；第一项就是首图。导入即启用，但不会自行发布。
4. 自动发布选择“已审核文案库”。不再识图或调用AI改写。默认避免相同账号重复使用同一变体；可显式允许复用。

```json
[{"externalId":"attachment-001-v1","sourceKey":"attachment-001","title":"When closeness feels overwhelming","caption":"A reflection on asking for space and staying connected.","pages":["When closeness feels overwhelming","You can need space and still care about someone.","Try saying: I need a quiet evening. Can we talk tomorrow?"]}]
```

同编号同内容重复导入会跳过；同编号不同内容拒绝覆盖，需使用新版本编号。文案可停用，已创建任务继续使用原快照。
目前提供 JSON 导入及原文导出，不使用或消耗 Grokbot 凭证/额度，也未创建新的机器人API。

## 统计口径
同文案指标题、发布文案、逐页叠字一致的版本，和来源分组分开。绑定以本地任务ID + 授权账号 + 官方作品ID精确匹配，不用相同标题或批次猜测。来源和样式在创建时固定，最终文案在生成完成转入绘图时保存。
报表沿用现有日期/分组权限；内容按批次创建时间筛选，当前累计数据来自每账号最近100条归档作品。读取上限5000任务、10000发布记录，超出会提示缩短周期。默认只用满24小时、已有播放数据的作品计算均播、高播率；缺失指标显示 —，不当作0。不同账号、发布时间和题材会影响表现，不能据此认定样式导致流量变化。
历史任务从原生成任务保留的 plan 恢复文案身份；未记录的样式标为未知，缺失文案单独列出。没有官方返回的收藏、完播或观看时长不补造。

## 情感心理学样式更新
现有20套均面向情绪共鸣、关系困惑、内心独白和沟通建议。保留经典黑白、奶油杂志、深夜独白、私信信笺、关系对话、留白引语、极简短句；其余13套已换成情感关系系列。旧绑定对新批次自动采用对应替代样式，历史记录与已创建任务继续使用原样式编号和布局。

# 心理学图文自动发布：200 账号 × 3 条/日容量审计

日期：2026-09-20。审计代码基线：localfactory 2e58468；中台使用本机 sibling 仓库只读检查，未验证其本地 HEAD 与线上部署完全一致。

## 结论与范围

当前正常路径具备每 20 条合并提交能力，但不应据此承诺每天 600 条稳定发布。首要问题是组内失败隔离、临时素材恢复、账号查询故障分类，其次是账号校验放大、选题避重及记录分页。此次只增加隔离测试、基准测试和报告，没有修改生产逻辑、部署、调用真实发布 API 或消耗 AI 额度。

用户明确以图文爆款复刻为主。容量模型为每天 200 个账号、每账号 3 条图文，最多 6 张/条，即 600 条、3,600 张图片。视频共用的分组和账号校验也受相关问题影响；本次没有测量视频编码吞吐。

## 测试方法

- 使用真实数据库 migrations、创建批次、图文生成后交接、上传检查点、组提交、回执落库、失败重试与 worker claim 处理函数。D1 替换为内存 SQLite，中台 fetch 严格限制在 hub.invalid 并全量模拟，未知网络请求立即失败。
- AI 生成结果使用固定六页计划，JPEG 使用四字节格式标记；它们只用于验证传输接口和分组逻辑。正常路径直接设置 worker running/done 状态，未模拟云端 Workflows 调度和真实 worker 子进程；claim 的 503 路径另行调用真实 handler。

## 本轮结果与记录方式

600 条正常路径断言已完成：200 个账号每账号恰好 3 条，3,600 次模拟上传，30 个唯一中台批次，600 条本地提交回执。单次 600 条请求被拒绝。初版脚本在最后一个 claim 故障场景因测试工人未声明 psychologyBatchUpload 能力而断言失败；该参数已修正，故障场景单独补跑，进程退出 0，全部断言通过。没有把初版进程退出码写成全程通过，也没有保留或报告该次完整模拟耗时/查询计数。脚本支持 --faults-only，完整 600 条跑法仍可复现。

模拟正常路径已通过的断言不等同于 TikTok 真正发布 600 条成功。故障场景和本机基准的实际输出见同目录 JSON 文件。

### 素材清理的准确边界

中台源代码的孤立素材宽限为 15 分钟，清理只在 daily-maintenance cron 触发（当前配置 23:00 UTC，即北京时间 07:00）。不是素材达到 15 分钟就自动消失，也不是每分钟执行该清理。未提交分组没有对应中台素材引用，若图片已上传超过 15 分钟且跨过实际清理执行，就可能被删除。已引用素材会跳过清理。上述时刻是本地中台配置检查结果。

### 并发和耗时

读取到工人配置为单台 windows-local、renderConcurrency=1，publishConcurrency 未配置因而使用默认 1。图文的本地卡片渲染、底图下载和上传全部占用 render lane；单独提高 publishConcurrency 并不会加快这段。

只读生产统计中，psychologyAutomation 的 psychology 类型已完成样本仅 2 条，领取至完成均值约 24.9 秒（23.917–25.785）。机械外推 600 条约 4.15 小时，但样本不足，且不含前置云端 AI 生成和最终 TikTok 发布，不能用作 SLA。预计处理跨度超过首次排期时，中台可能顺延；不能把“已生成”或“已交中台”等同于按时发布成功。

本次真实 Chrome 文字卡测速：72 张总计 10.246 秒，平均六页/条 0.854 秒，P95 1.032 秒；JPEG 平均 78,879 字节。纯本地文字渲染线性外推 600 条约 8.54 分钟。与历史执行时间差距说明不能只按画图速度估计端到端容量。该样本使用固定短文，复杂文案/背景图片不在该测量范围。

账号范围计算单独测量（各 10 次，Node 本机，有同时运行的模拟负载）：20 账号约 1.57 ms，200 账号约 60.66 ms，400 账号约 250.13 ms。scopeOfficialAccess 每账号调用 accountMatchesProject，重复规范化整个分组和分配表，存在近似平方增长；这些数字不代表 Cloudflare CPU 实测。

### 外部服务与素材量

只读生产同行库计数为图文 216、视频 28。若要求每日 600 条来源全部不同，216 条不足；如果允许矩阵复用，应明确每账号冷却/重复策略。

云图文工作流没有应用级全局 AI/素材请求限流；600 条至少对应 600 次提取计划请求，格式修正循环最多 3 轮且可能主备切换。底图库按封面/内容角色搜索，有背景图的帖子还增加搜索和下载。此次未实测供应商余额、账号额度、429 频率或官方发布成功率。

中台机器 API 源码默认共享额度为每天 5,000 次上传、5,000 条任务、100 GiB，且可按活跃账号扩大或被环境变量覆盖。600 条/3,600 张在该默认值内，但小说推文等模块共用额度、失败重传也需计算。不是每个心理学账号独立拥有 5,000 次，亦不是已验证的线上可用余额。

## 建议验收顺序

1. 修复组内失败隔离、失效素材重传、claim 暂时故障分类；使用同一故障注入脚本证明可恢复且无重复发布。
2. 增加云生成限流、账号查询缓存/索引、日计划与任务分页；再按实测吞吐配置图文独立并发，避免挤占视频渲染。
3. 明确来源复用规则并补充素材。在完成这些改动后，按 20 账号 × 3 条、再 50 账号 × 3 条、最后 200 账号 × 3 条渐进验收真实流水线，记录 AI/上传 P95、失败率、重试恢复率、实际发布时间及剩余额度。

本轮未发布任何测试内容。下一步应先实施可靠性修复，再进行带明确发布内容和账号的线上小批量验收。
